## Frequently Asked Questions about Download and First Launch

??? question "Windows SmartScreen says the file is unrecognized: is it safe?"
    **Yes, it is completely safe.** Pozzo Launcher is free open-source software created by the community and does not purchase costly commercial code-signing certificates from Microsoft. When Windows SmartScreen displays the *"Windows protected your PC"* warning, simply click **"More info"** and then **"Run anyway"**. You can inspect the public source code on GitHub at any time.

??? question "Where are my data, settings, and covers stored?"
    All your data (SQLite database, downloaded metadata, favorites, and box art images) are stored in the standard user directory for your operating system (`%LOCALAPPDATA%\PozzoLauncher` on Windows, `~/Library/Application Support/PozzoLauncher` on macOS, `~/.local/share/PozzoLauncher` on Linux). The executable and settings do not touch the system registry.

??? question "How do I update Pozzo Launcher to a new version?"
    Pozzo Launcher includes an automatic update checker: when a new release is available on GitHub, an unobtrusive notification appears in the interface with a button to download and apply the update in one click, preserving all your ROMs, covers, and settings.

??? question "How do I get started after downloading?"
    On first launch, the application welcomes you with a setup wizard to point to your ROMs directory and link your PC store accounts (Steam, Epic, GOG). Check out the [Getting Started Guide](guida.md) or the chapters [Installation and Updates](installazione.md) and [The Library](libreria.md).
