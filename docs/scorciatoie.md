# Scorciatoie da tastiera

Pozzo Launcher si usa anche senza mouse: tastiera sul PC e controller in Big Picture.
Sul Mac al posto di **Ctrl** si usa **Cmd (⌘)**; l'app mostra da sola il simbolo giusto nei menu, nei suggerimenti
e nel pannello delle scorciatoie (`?` oppure **Ctrl/Cmd + /**, o *Impostazioni → Generale → Scorciatoie da tastiera*).

Le scorciatoie **non scattano mentre scrivi** in un campo di testo (tranne quelle con Ctrl/Cmd pensate per questo, come la ricerca).
Copia, incolla, ricarica e le altre combinazioni del browser restano intatte.

### Personalizzarle

Nel pannello delle scorciatoie, **Cambia** accanto a un'azione registra la nuova combinazione (Esc annulla); se è già usata da
un'altra azione l'app lo dice e non la salva. **Ripristina** torna a quella originale. Cambiando un'azione che ne ha due
(per esempio «Indietro») la nuova combinazione sostituisce entrambe. I tasti `/`, `Esc` e `Enter` non si possono cambiare.
Le scelte sono salvate nel browser dell'app (`gs.shortcuts`).

## Controller (Big Picture)

Funziona con la mappa standard della Gamepad API: Xbox, PlayStation (✕ ○ □ △) e Switch Pro. Le etichette si adattano da sole.
Il polling parte solo quando un controller è collegato (premi un tasto la prima volta) e rallenta se non lo tocchi.

| Tasto | Azione |
|---|---|
| A (✕) | Conferma / apri |
| B (○) | Indietro |
| X (□) | Preferito |
| Y (△) | Cerca |
| LB / RB | Categoria precedente / successiva |
| LT / RT, stick destro | Pagina su / giù |
| Croce o stick sinistro | Naviga (tenendo premuto si ripete) |
| Start | Menu della schermata |
| L3 | Torna alla Home |
| R3 | Mostra/nascondi la legenda in basso |
| Select / View (tocco) | Pannello con tutti i comandi |
| Select tenuto 1 secondo | Esci da Big Picture |
| Select + A | Musica: play/pausa |
| Select + RB / LB | Brano successivo / precedente |
| Select + X | Discord: microfono muto |
| Select + Y | Discord: audio disattivato |
| Select + B | Esci da Big Picture |
| Select + Start (tenuti) | Chiudi il gioco in esecuzione |

Gli stick hanno una zona morta, i controller collegati insieme funzionano tutti. Con un gioco in esecuzione i comandi
dell'interfaccia sono sospesi; restano Select + Start e i comandi musica/Discord.

Vedi anche [Big Picture](bigpicture.md).
